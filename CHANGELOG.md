# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-11-15

### Added
- Initial release of Sanity Image URL Generator Plugin
- Image selection from Sanity media library
- Hotspot and crop support
- Aspect ratio selector with common presets
- Custom aspect ratio input
- Multiple width selection for responsive images
- Format selection (auto, WebP, JPEG, PNG)
- Quality slider (1-100)
- Fit mode options
- Live preview functionality
- Copy-to-clipboard for multiple formats:
  - Single URL
  - Responsive HTML with srcset
  - Markdown format
  - JSON format
- TypeScript support with full type definitions
- Comprehensive documentation

### Features
- Seamless integration with Sanity Studio v3
- Real-time URL generation
- Production-ready responsive markup
- Configurable plugin options
- Programmatic API for custom usage
